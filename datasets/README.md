# AI Smart Kitchen — Synthetic Ingredient Substitution Dataset

This dataset was created specifically for the **AI Smart Kitchen** educational project.

It was generated synthetically for this project and was **not copied from a third-party ingredient-substitution dataset**.

## Contents

- Records: 692
- Core substitution relationships: 106
- Format: CSV
- RAG-ready text field included: `rag_text`

## Main Facets

1. `original_ingredient`
2. `substitute`
3. `ratio_or_guideline`
4. `cooking_context`
5. `dietary_tags`
6. `expected_impact`
7. `limitations`

Additional metadata fields include:

- `id`
- `suitability`
- `generation_method`
- `validation_status`

## Intended Use

The dataset is intended for educational, experimental, NLP, RAG, and AI-agent projects.

For AI Smart Kitchen, it is used as the knowledge base of the **Ingredient Substitution Agent**.

## Important Quality Note

The records contain synthetic culinary guidance and have not been professionally validated.

Ingredient substitutions may depend on recipe context, preparation method, dietary restrictions, allergies, and specific products.

The field `validation_status` is therefore set to `manual_review_recommended`.

## Dataset Provenance

This synthetic dataset was created specifically for the AI Smart Kitchen project with AI assistance.

It was not created by copying an existing ingredient-substitution dataset.
