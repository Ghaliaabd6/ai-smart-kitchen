AI Smart Kitchen --- Synthetic Ingredient Substitution Dataset
This dataset was created specifically for the AI Smart Kitchen
educational project. It was generated synthetically for this project and
was not copied from a third-party ingredient-substitution dataset.
Contents
- Records: 692
- Core substitution relationships: 106
- Format: CSV
- RAG-ready text field included: rag_text
Main facets
1. original_ingredient
2. substitute
3. ratio_or_guideline
4. cooking_context
5. dietary_tags
6. expected_impact
7. limitations
Additional metadata fields include id, suitability,
generation_method, and validation_status.
Intended use
The dataset is intended for educational, experimental, NLP, RAG, and
AI-agent projects. For AI Smart Kitchen, it can serve as the knowledge
base of an Ingredient Substitution Agent.
Important quality note
The records are synthetic culinary guidance. They have not been
professionally validated. Substitutions can depend on recipe chemistry,
brands, allergies, dietary restrictions, and preparation method. The
field validation_status therefore defaults to
manual_review_recommended.
